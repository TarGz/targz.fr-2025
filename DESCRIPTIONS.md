## What the current column shows

Every piece has a description. 52 of them are the same generated sentence with the title
and the specs swapped in, so the column reads as one line repeated down the page. That is
the problem: the copy is a spec sheet, and none of it says what the piece is.

## Pieces that need more than a description

**Y1 / Y2** are Matildas series. Beat 1 is drafted from the pattern only. If there is a
planted portrait in the density, see the found/planted section before writing beat 2, and
decide named or unnamed.

**Maybe you just....** is planted, a hidden message. Beat 2 confirms something is in there
without saying what. The title already does the teasing.

**Christopher Walken Portrait** is literal, not hidden. The face is the first thing you see,
so there is no artefact to reveal. Beat 1 plus a turn, if there is one.
